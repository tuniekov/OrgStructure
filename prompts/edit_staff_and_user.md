# Редактирование сотрудников и пользователей modx, windows и говорилки.
## Введение
Нужен инструмент для редактирования сотрудников, привязки и редактирования пользователей modx, windows и openfire(говорилки). Текущее редактирование слишком сложное. Директору будет некогда разобраться и даже если разберется, то быстро забудет.

Я уже начал делать такой инструмент для modx28. Только сейчас он редактирует только структуру организации и сотрудников.
Надо добавить редактирование пользователей modx, windows и openfire(говорилки).
[Скриншот интерфейса](https://disk.yandex.ru/i/O8YVOxFtvEAucQ)
